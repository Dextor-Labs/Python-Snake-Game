# Snake-game

A simple Snake game made with Python and pygame.

## About

This is a beginner Python project where I am learning how to build a small 2D game using pygame.

The game includes:

- Snake movement
- Food spawning
- Score tracking
- Collision detection
- Game over screen
- Restart and quit controls

## Tech Used

- Python
- pygame
- nvim
- vscode
